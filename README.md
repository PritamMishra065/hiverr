# Signal Desk — SpotifyCares AI Support Agent

A runnable prototype for the Hiver SDE Intern assignment. It uses the Customer Support on Twitter archive, narrows it to the **SpotifyCares** brand, and exposes an evidence-first support agent that classifies incoming messages, drafts grounded replies, and makes the escalation decision explicit.

## Quick start (< 5 minutes)

```bash
python -m venv .venv
# Windows:
.\.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Open **http://127.0.0.1:5000**. The included `data/twcs_spotify.csv` is a curated brand slice, so the demo does not need the 177 MB source archive at runtime.

### LLM mode (optional)

Set a [Groq](https://console.groq.com) API key to enable LLM-powered classification and reply generation:

```bash
# Windows:
set GROQ_API_KEY=gsk_your_key_here
# macOS/Linux:
export GROQ_API_KEY=gsk_your_key_here

python app.py
```

Without the key the app runs in **keyword mode** (deterministic, no external API calls). With the key it uses Groq's LLM for smarter intent detection and more natural, grounded replies. Both modes use the same TF-IDF retrieval and escalation logic.

## Reproduce evaluation results

```bash
# Generate the golden evaluation set (200 stratified examples)
python create_golden_eval.py

# Run the full evaluation harness (3 systems, all metrics)
python evaluate.py
```

Results are printed to stdout and saved to `data/eval_results.json`.

## What is implemented

### Core agent pipeline

1. **Intent classification** — Two modes: (a) keyword rules with 7 intents as a deterministic fallback, (b) LLM-powered classification via Groq when an API key is provided. Both produce an intent label, confidence score, and matched cues.

2. **Evidence retrieval** — TF-IDF (bigram, sublinear TF) over 43,265 historical SpotifyCares replies. The top-3 most similar replies are returned with match scores, grounding the draft in real brand behavior.

3. **Escalation decision** — A transparent policy that chooses `auto-handle` or `escalate` based on: sensitive language detection, intent confidence threshold (0.55), retrieval match strength, and intent risk category. The reason is always stated.

4. **Grounded draft reply** — In keyword mode, extracts action patterns from retrieved evidence and composes template responses. In LLM mode, prompts the model with the customer message, detected intent, and retrieved historical replies to generate a natural, brand-consistent response.

### Evaluation

- **Golden evaluation set** — 200 hand-labelled examples, stratified 25 per intent, with an [annotation guide](data/annotation_guide.md).
- **Three systems compared** — majority-class baseline, TF-IDF nearest-neighbor baseline, and the Signal Desk agent.
- **Automated metrics** — per-intent precision/recall/F1, macro and weighted F1, escalation accuracy/precision/recall/F1, confusion matrices.
- **Rubric-based reply quality judge** — 5 dimensions (relevance, groundedness, tone, actionability, safety) weighted into a composite score. Implemented as a deterministic proxy; designed for drop-in replacement with an LLM judge.
- **Judge-human agreement** — measured by comparing judge composite scores against human escalation labels.

### Headline results (keyword mode)

| Metric | Signal Desk | Majority baseline | TF-IDF NN |
|--------|-------------|-------------------|-----------|
| Intent accuracy | **87.5%** | 12.5% | 98.5% |
| Macro F1 | **0.875** | 0.028 | 0.985 |
| Escalation accuracy | **90.0%** | 54.5% | 100% |
| Reply quality | **0.734** | 0.562 | 0.541 |

## Deploy to Render (recommended, free tier)

1. Push this repo to GitHub.

2. Go to [render.com](https://render.com) and sign in with GitHub.

3. Click **New > Web Service** and connect your repo.

4. Render auto-detects `render.yaml`. Set these:
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `gunicorn app:app --bind 0.0.0.0:$PORT --timeout 120`

5. Under **Environment > Environment Variables**, add:
   - `GROQ_API_KEY` = your Groq key (or leave blank for keyword mode)

6. Click **Deploy**. Your app will be live at `https://signal-desk-xxxx.onrender.com`.

### Alternative: Railway

1. Push to GitHub.
2. Go to [railway.app](https://railway.app), connect repo.
3. Add env var `GROQ_API_KEY`.
4. Railway auto-detects the `Procfile`. Deploy.

## Key decisions

See the [decision log in REPORT.md](REPORT.md#7-decision-log) for the full list. Notable choices:
- SpotifyCares was chosen for its high volume of brand replies and consistent troubleshooting patterns.
- Dual-mode (keyword + LLM) ensures the app works without any API key while being significantly better with one.
- Billing, account, and cancellation intents always escalate by default.
- The confidence score is a heuristic in keyword mode, not a calibrated probability — this is stated in the UI and report.
